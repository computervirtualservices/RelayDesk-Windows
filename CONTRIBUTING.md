# Contributing to RelayDesk

Contributions, bug reports, documentation corrections and repeatable Windows test results are welcome.

1. Open an issue describing the expected behavior and actual behavior.
2. Make focused changes on a branch and submit a pull request.
3. Build with the .NET 10 SDK and validate on Windows 11.
4. Run `Check-Environment.ps1` and test with **private or unlisted** destinations first.
5. Never commit streaming keys or personal stream URLs.

Please be accurate about support status: working code ≠ verified public broadcast. This project is not affiliated with YouTube, Rumble, Meta, TikTok, LinkedIn, OBS Studio, or the original OBS Multi-RTMP plugin.
