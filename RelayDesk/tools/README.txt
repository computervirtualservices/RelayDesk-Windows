RelayDesk 2.0 external dependencies — NOT INCLUDED in the source archive.

Place ffmpeg.exe and mediamtx.exe in this directory (or beside RelayDesk.exe or on PATH).

Download only from reputable official projects:
https://ffmpeg.org/download.html
https://github.com/bluenviron/mediamtx/releases

Use a Windows FFmpeg build with h264_nvenc and libx264 if you want both encoder modes.
See README.md and Check-Environment.ps1 for setup and security notes.
