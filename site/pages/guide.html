Windows setup

How to multistream from OBS with RelayDesk

Follow this local Windows 11 setup for the RelayDesk source-code prototype. You need Visual Studio 2026 or the .NET 10 SDK, OBS Studio, FFmpeg and MediaMTX.

Release status: development source only

This walkthrough describes the intended current code path. The project has not yet passed a verified Windows compile and all-platform live rehearsal. Start with a private or unlisted destination.

Requirements

  • Windows 11 x64 and .NET 10 SDK or Visual Studio with the .NET desktop development workload.
  • OBS Studio producing H.264 video and AAC audio.
  • A reputable build of FFmpeg; NVIDIA users need a build with h264_nvenc.
  • MediaMTX Windows executable.
  • Active, permitted live streaming on each target platform, with its current RTMP/RTMPS server and stream key.

Step-by-step

  1. Get the repository.

    Clone the RelayDesk source and open RelayDesk/RelayDesk.csproj in Visual Studio 2026.

  2. Compile for Windows.

    Run ./Build-Windows.ps1 from PowerShell (or build in Visual Studio). A publish output is expected at publish/RelayDesk.exe.

  3. Provide streaming engines.

    Place ffmpeg.exe and mediamtx.exe inside publish/tools. These executable dependencies are deliberately not redistributed here. Run ./Check-Environment.ps1 to see expected dependency checks.

  4. Configure destinations.

    Launch RelayDesk, choose Add Six, edit each destination with its official server URL and key, select an appropriate output profile, then enable that destination.

  5. Start the local relay.

    Start at least one configured destination in RelayDesk. It starts MediaMTX and FFmpeg processes. Workers may initially report waiting for OBS input.

  6. Connect OBS to localhost.

    Set OBS Settings → Stream → Custom. Use the RTMP server and stream key below. Then start streaming in OBS.

  7. Verify each platform.

    Confirm ingest status, preview quality and Go Live controls on the platform itself. FFmpeg's outgoing frame counter alone is not proof of a public broadcast.

OBS local stream settings

These are non-secret loopback settings for OBS to send video into RelayDesk, not the private destination streaming credentials.

Stream key: studio

What upload speed do I need?

The six initial profiles have an estimated aggregate video bitrate of about 64.5 Mbps. Including audio, protocol overhead and at least 25% headroom, plan for approximately 82 Mbps sustained upload as a starting point. Measure performance under your actual network and GPU load. Changing any bitrate changes this estimate.

RTMP vs RTMPS

Use RTMPS where supported. RelayDesk validates destination addresses as RTMP/RTMPS URLs and stores stream keys under Windows DPAPI. Some services issue per-session credentials; you must update them in RelayDesk before your broadcast.

Privacy and security

The service keys you enter are not put into this website. The application stores encrypted keys locally. Active FFmpeg processes expose the assembled outbound URL to suitably privileged local process inspection, so avoid sharing process dumps or verbose logs. Do not open the localhost RTMP listener to the public internet.

Known gaps

No signed installer, shared GPU encoding, direct OBS WebSocket scene switching, provider OAuth, scheduling, automatic event creation or verified broadcast status API is included yet. See the repository README for the most current known limitations.
