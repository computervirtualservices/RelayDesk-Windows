Project overview

About RelayDesk Windows

An experimental, independent Windows multistreaming application for users who want control over their own OBS-based live broadcasting workflow.

Why another multistream tool?

Desktop broadcasters sometimes want a local routing dashboard without sending video to a paid cloud middleman. RelayDesk receives one OBS feed and launches independent FFmpeg outputs from the user's own Windows computer. The source is published to enable scrutiny, extension and community testing.

Technical architecture

The current source uses C#, WPF and .NET 10. MediaMTX binds to 127.0.0.1:1935 as the localhost RTMP input. FFmpeg workers handle scaling, portrait cropping or padding, encoding and RTMP/RTMPS forwarding. NVIDIA H.264 NVENC is an option; CPU x264 is available as a fallback.

Independence and attribution

RelayDesk is not the OBS Multi-RTMP plugin. It is a separately generated Windows application inspired by the general simultaneous-multistreaming use case. It is not endorsed by, partnered with or affiliated with OBS Studio, sorayuki/obs-multi-rtmp, YouTube, Rumble, TikTok, Meta or LinkedIn.

Development roadmap

  • Validate compilation and integration tests with a Windows machine and real OBS input.
  • Measure CPU/GPU resource use under multiple concurrent output profiles.
  • Add shared encodes and GPU scaling for matching destination formats.
  • Implement OBS WebSocket control, safe scheduling and better per-platform health checks.
  • Produce signed Windows installers after compatibility and security review.

Open development

The MIT-licensed source, contribution guide, security notes and CI workflow are in the public GitHub project once published. No streaming credentials, third-party executable binaries or Windows installer are distributed in the source archive.
