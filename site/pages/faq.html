RelayDesk multistreaming FAQ

Clear answers to common questions about OBS, 4K, Windows, TikTok, Instagram, YouTube, Rumble, Facebook and LinkedIn.

Can RelayDesk restream a 4K OBS feed to six platforms?

The source implements forwarding a single OBS RTMP feed to six independent output workers, with output-profile options that include 4K, 1080p and portrait video. It has not been verified end to end on Windows and every platform. Availability and 4K acceptance depend on the service and account.

Does every destination receive a 4K picture?

No. RelayDesk has separately configurable output profiles. The initial presets use YouTube 4K; Rumble 1080p; Facebook and LinkedIn 1080p; and TikTok and Instagram portrait 720p. Rumble has an adjustable 4K profile, but acceptance is not established.

Do TikTok and Instagram accept ordinary stream keys?

Not always. TikTok third-party stream access and Instagram Live Producer eligibility are account-dependent. Obtain credentials only through each provider's authorized live interface and verify current rules before scheduling a show.

Is RelayDesk an OBS Studio plugin?

No. RelayDesk is a standalone C# WPF desktop application. OBS sends one video stream to a local MediaMTX server; RelayDesk starts and manages separate FFmpeg outputs. It is not affiliated with OBS Studio or the sorayuki OBS Multi-RTMP project.

Is RelayDesk free and open source?

The repository source is published under an MIT license. Hosting, bandwidth and access to streaming platforms may have separate requirements. FFmpeg and MediaMTX are not redistributed in this project.

Does the Windows app work without installing anything else?

No. At this stage you need to build the WPF project with the .NET 10 toolchain and provide FFmpeg and MediaMTX. There is no tested one-click signed Windows installer yet.

What NVIDIA GPU features are supported?

The FFmpeg command generator can use H.264 NVENC on supported NVIDIA hardware if the selected FFmpeg build includes it. Software H.264 encoding is a fallback. GPU hardware scaling and shared encoders are not implemented, and simultaneous session capability needs testing.

Does RelayDesk automatically confirm that I am live on each platform?

No. The app can report FFmpeg stream activity but cannot certify that a provider has started a public broadcast. Check each site's streaming dashboard and Go Live controls.

Will RelayDesk automatically schedule prerecorded live streams?

No. Prerecorded video scheduling and platform event creation are not included in the current source version. They are potential future additions.

Can I use RelayDesk to stream to another custom RTMP server?

Yes. The source supports custom RTMP/RTMPS destinations if you supply a compatible server address and stream key. Always validate the destination rules and codecs.

Does the project collect my livestream keys through the website?

No. This documentation site contains no account login or stream-key entry. The Windows application protects saved destination keys using DPAPI, but active FFmpeg command lines still carry assembled publish URLs locally.

How can I contribute or report bugs?

Use the GitHub issue tracker or submit a pull request. Remove stream keys, private service URLs, user details, and unredacted FFmpeg commands before posting logs.
